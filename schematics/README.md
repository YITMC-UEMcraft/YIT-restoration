# 投影文件目录

本目录**只存放与燕京理工学院校园复原相关**的投影与结构文件。

## 放什么

- 校园建筑、道路、景观的分区投影（`.litematic` / `.schem`）
- 对外发布的单体建筑结构文件
- 阶段性备份（可选，建议只保留最近一版）

## 不放什么

- 与校园复原无关的个人作品、练习存档
- 第三方地图、付费建筑、他人作品
- 完整世界存档（体积大，走 Releases 分发）

## 命名

```text
YYYYMMDD_区域_作者.litematic
例：20261106_图书馆_张三.litematic
```

## 提交方式

1. 先放到 `incoming/` 目录；
2. 在 PR 中说明坐标范围、所用模组版本，并附截图；
3. 维护者审核后移入本目录正式归档。

详细规范见 [CONTRIBUTING.md](../CONTRIBUTING.md) 与 [docs/协作规范.md](../docs/协作规范.md)。
