# 协作规范

本文件约定社团成员在复原工程中的建造与提交标准，目的是让不同人建的成果能无缝拼接。

## 1. 版本与模组

- 统一使用整合包 `燕理复原 1.20.1`（Fabric Loader 0.16.14）；
- 不得私自增减或升级模组；确需变更请先提 Issue；
- 建造统一在**创造模式**下进行。

## 2. 坐标与分区

- 以校园主入口为原点，按「区域」划分建造范围；
- 每个区域在 Issue 中登记，格式：`区域名 | 坐标范围 | 负责人`；
- 跨区域的道路、绿化、水系由维护者统一规划，个人不要自行延伸。

## 3. 比例与风格

- 建筑比例以「1 方块 ≈ 0.5 米」为基准，层高统一 3 格；
- 道路宽度、人行道、绿化带按现有主路的标准执行；
- 材质以原版方块 + 方块小镇（Yuushya）为主，避免混用风格差异过大的材质包；
- 不使用命令方块或数据包生成地形，地形改造走 WorldEdit。

## 4. 命名

- 投影文件：`YYYYMMDD_区域_作者.litematic`
- 区域目录：中文区域名，不带空格
- 截图：`YYYYMMDD_区域_说明.png`

## 5. 提交前检查

- [ ] 投影范围没有包含他人未完成的建筑
- [ ] 没有使用未授权的外部素材
- [ ] 文件名符合规范
- [ ] PR 描述包含坐标、模组版本与截图
- [ ] 没有带入 `saves/`、日志、玩家数据

## 6. 冲突处理

- 同一区域多人认领时，由维护者协调分工；
- 发现他人建筑被误删，先在 Issue 说明，不要自行回滚整个存档；
- 重大改造（拆分、迁移、重建）需两名以上维护者同意。
